Installer Positron AC / Install Positron AC

Positron AC est l’application qui relie cet ordinateur à votre compte. Installez-la, ouvrez-la, puis saisissez le code d’appairage. / Positron AC is the app that links this computer to your account. Install it, open it, then type the pairing code.

Windows

Installer Positron AC depuis le Microsoft Store / Install Positron AC from the Microsoft Store
  1. Installez Positron AC depuis le Microsoft Store. / Install Positron AC from the Microsoft Store.
  2. Ouvrez Positron AC depuis le menu Démarrer. / Open Positron AC from the Start menu.
  3. Saisissez le code d’appairage, puis validez. / Type the pairing code, then confirm.

macOS

Mac Apple silicon (M1 et suivants) : télécharger le .dmg / Apple silicon Mac (M1 and later): download the .dmg Mac Intel : télécharger le .dmg / Intel Mac: download the .dmg

Pour savoir quel Mac vous avez : menu Pomme, puis « À propos de ce Mac ». / To find out which Mac you have: Apple menu, then “About This Mac”.

  1. Ouvrez le fichier .dmg téléchargé, puis glissez Positron AC dans le dossier Applications. / Open the downloaded .dmg file, then drag Positron AC into the Applications folder.
  2. Ouvrez Positron AC depuis le dossier Applications. / Open Positron AC from the Applications folder.
  3. Saisissez le code d’appairage, puis validez. / Type the pairing code, then confirm.

Linux (64 bits, x86_64)

Debian, Ubuntu, Mint : télécharger le .deb / Debian, Ubuntu, Mint: download the .deb Fedora, openSUSE, RHEL : télécharger le .rpm / Fedora, openSUSE, RHEL: download the .rpm
  1. Installez le paquet : double-clic dans votre gestionnaire de logiciels, ou dans un terminal sudo apt install ./Positron-AC.deb (.deb) ou sudo dnf install ./Positron-AC.rpm (.rpm). / Install the package: double-click it in your software manager, or in a terminal sudo apt install ./Positron-AC.deb (.deb) or sudo dnf install ./Positron-AC.rpm (.rpm).
  2. Ouvrez Positron AC depuis le menu des applications. / Open Positron AC from the applications menu.
  3. Saisissez le code d’appairage, puis validez. / Type the pairing code, then confirm.
