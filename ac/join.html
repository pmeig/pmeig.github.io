AC est une application web (PWA) : vous l’ajoutez à votre appareil depuis le navigateur, sans passer par un magasin. / AC is a web app (PWA): you add it to your device from the browser, without a store.

Autres systèmes / Other systems

  • Windows : Microsoft Store
  • Android : Google Play
  • macOS : Asimov-AC.dmg
    Non signé, pour Mac Apple silicon (M1 et suivants) : la première fois, clic droit puis Ouvrir. Mac Intel non pris en charge pour l’instant. / Unsigned, for Apple silicon Macs (M1 and later): the first time, right-click then Open. Intel Macs are not supported yet.
  • Linux (Debian, Ubuntu, Mint…) : Asimov-AC.deb
    sudo apt install ./Asimov-AC.deb
  • Linux (Fedora, openSUSE, RHEL…) : Asimov-AC.rpm
    sudo dnf install ./Asimov-AC.rpm
  • iPhone, iPad, autres / others : application web (PWA) : dans le navigateur, « Sur l’écran d’accueil » (Safari) ou « Installer » (Chrome, Edge). / web app (PWA): in the browser, “Add to Home Screen” (Safari) or “Install” (Chrome, Edge).
